Verifiedchecked 2026-11-11

Open-source AI agent that runs on the phone

The model runs on the phone through LiteRT-LM, and every request goes through a pipeline you can read and change. By default a risky action waits for your confirmation.

  • Pipeline editor with 14 node types, in the app and as a single offline HTML file.
  • Each run records its seed, sampler, versions and the SHA-256 of every model file. A finished run can be repeated on the device and compared byte for byte.
  • SQLCipher database, API keys sealed under an Android Keystore key, and a build check that keeps exports off the network.
  • MCP tools with allowlists enforced where the tool runs. Interface, bundled pipelines and help in English, Spanish and Russian.
