# alexeyw.github.io

Root of https://alexeyw.github.io/. It redirects to the Colored Seeds site
(https://alexeyw.github.io/colored-seeds/, repository `alexeyw/colored-seeds`) and holds the Google
Search Console verification file for the whole domain.

Do not delete the `google*.html` file: Google re-checks it, and the Google Cloud OAuth branding of
Colored Seeds depends on this domain staying verified.
