Проверенопроверено 2026-11-08

ИИ-агент с открытым кодом, который работает на телефоне

Модель работает на телефоне через LiteRT-LM, а каждый запрос проходит по пайплайну, который можно прочитать и изменить. По умолчанию рискованное действие ждёт подтверждения.

  • Редактор пайплайнов с 14 типами узлов: в приложении и в виде одного HTML-файла, который работает без сети.
  • Каждый запуск записывает seed, сэмплер, версии и SHA-256 каждого файла модели. Завершённый запуск можно повторить на устройстве и сравнить побайтно.
  • База на SQLCipher, ключи API запечатаны ключом Android Keystore, а проверка при сборке не даёт экспорту выйти в сеть.
  • Инструменты MCP со списками разрешений, которые проверяются там, где инструмент выполняется. Интерфейс, встроенные пайплайны и справка на английском, испанском и русском.

AI Native EngineeringAI Native Engineering

Кодинг-агенты работают на всех этапах SDLC. За инженером остаются спецификация, архитектура и решения о выпуске.

Spec-Driven Development (SDD)

Каждая задача начинается с письменной спецификации: затронутые классы, интерфейсы, тесты и файлы. Реализация начинается только после её утверждения.

Наблюдаю изнутри процесса

AI-Driven Development (AIDD)

Агенты ведут исследование, реализацию, тесты, ревью и рефакторинг через пул-реквесты. Перед использованием библиотеки или API сверяется официальная документация.

19 из последних 30 коммитов называют ИИ соавтором. Смерженных пул-реквестов: 610.

Human-in-the-loop gates

Контрольные точки: утверждение плана, передача дизайна, ревью пул-реквеста и релиз. Необратимые действия требуют явного подтверждения человеком.

Наблюдаю изнутри процесса

Context engineering

Манифест агента как источник истины, правила по путям, генерируемая карта кода и долговременная память с извлечением при старте сессии.

Наблюдаю изнутри процесса

Multi-agent orchestration

Субагенты для параллельного исследования и независимого ревью кода, переиспользуемые команды и навыки, инструменты по MCP.

Наблюдаю изнутри процесса

Guardrails as code

Хуки перед выполнением операций shell, git и пул-реквестов. LLM-гейт отклоняет коммиты и пул-реквесты, в которых утверждения не подкреплены доказательствами.

Наблюдаю изнутри процесса

Agentic code review

Агент перечитывает реальный дифф как ревьюер по чек-листу. Каждый дефект получает регрессионный тест, проход повторяется, пока не перестанут находиться новые замечания. Затем ревью проводит человек.

CI quality gates

Detekt, Ktlint, Android Lint, порог покрытия 75% в Kover, архитектурные тесты на Konsist, скриншотная регрессия на Roborazzi и инструментальные тесты.

Эталонных скриншотов: 799. CI-воркфлоу: 4.

ADR and docs as code

Architecture Decision Records по каждому значимому решению. Документация меняется в том же пул-реквесте, ссылки проверяются в CI.

Release engineering and supply chain

Интеграционные ветки по фазам держат main готовым к релизу. Проверка зависимостей по PGP и SHA-256, CI-экшены закреплены по SHA коммита, сканирование секретов.
