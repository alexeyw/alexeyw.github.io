for Claude Code

A live map of what your AI agent is doing, in a pane beside the chat. Files, shell, network, memory, subagents, skills and hooks light up as they are used. It runs on your machine and sends nothing anywhere.

This page runs lot-map's classifier, drawing and row code as released in 0.12.0, with the types stripped and nothing else changed but the file extensions in its imports. Only Claude Code is stood in for: a clock and a list of invented calls. Every path, address, key and name in them is made up.

What it takes from a call

Handed everything. Keeps a name.

A call toThe row saysNever
A filethe last two parts of its paththe rest of the path, the text read or written
A web addressthe host alonea login, password, path or query
A shell commandthe short description Claude wrote for it, or the command's namethe command line
A searchthe tool's namethe pattern or the query
A memory callthe tool's name, a record numberthe text or the query
A subagentthe short description it was started withits prompt

Like any mod that follows tool calls, lot-map is handed each call whole. It makes no network requests, reads no files, runs no processes, calls no model and changes no call. The full statement is PRIVACY.md, and the list of everything the mod asks of Claude Code is checked on every change by a public test.

Reads at a glance

A pulse runs from the centre to the station at work. A ring shows how full the context is. A failed call and a hook's refusal stay marked until your next message.

Where it runs

The Claude desktop app, VS Code and the terminal. In kitty, Ghostty and iTerm2 3.7.8 or newer the terminal shows the map as a picture; anywhere else, in braille dots or as rows.

Yours to set

Seven languages, light and dark, your own colours, which tools count as memory, which MCP server sits on which station. Every option with a picture.
